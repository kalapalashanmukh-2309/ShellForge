Manage concurrent work
End a command with &. Use jobs to list tasks and wait to join them.
Explore Week 10
threads shows mutex synchronization. race-demo demonstrates lost updates. monitor on enables the ten-second heartbeat.
Interrupt or exit
Ctrl+C interrupts the foreground program. Ctrl+D or exit closes the shell.

Quotes and escaping work. Variable expansion, wildcards, command substitution, &&, and full job control are outside this project’s scope.
